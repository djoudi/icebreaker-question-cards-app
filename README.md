# بطاقات الأسئلة — نسخة المدرب

نسخة مستقلة من منصة «اختَر رقماً وشاركنا!» بتجربة يقودها المدرب. يختار المدرب القسم والبطاقة، ثم يقرأ السؤال وخياراته للمتدرب ليجيب شفهياً. لا يوجد إدخال لاسم المتدرب أو الفوج، ولا تُسجَّل إجابات المشاركين.

## التشغيل على Windows

```powershell
cd icebreaker-question-cards-app
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

ثم افتح `http://127.0.0.1:5003`.

## طريقة الاستخدام

- اختر الأسئلة العامة أو الأمن السيبراني أو الوضع المختلط.
- اختر بطاقة مرقمة ليظهر سؤالها، أو استخدم الاختيار العشوائي.
- اقرأ السؤال وخياراته للمتدرب ليجيب شفهياً. لا تعرض الصفحة حقول إجابة.
- في أسئلة الأمن السيبراني ذات الإجابة الصحيحة، يمكن للمدرب كشف التصحيح والتفسير بعد النقاش.
- تفاصيل المدرب وسؤال المتابعة مخفية اختيارياً كي تبقى البطاقة واضحة.
- اختيار البطاقة يحجزها من الجلسة حتى بعد التمرير أو استبدالها أو تحديث الصفحة. سجل كل بنك منفصل. «جلسة جديدة» يعيد البطاقات بعد التأكيد.

حالة الجلسة تُخزّن محلياً في المتصفح، والأسئلة في ملفي JSON داخل هذا المجلد. لا توجد قاعدة نتائج أو بيانات متدربين.
